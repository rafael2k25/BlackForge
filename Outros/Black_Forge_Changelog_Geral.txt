CADASTRO DE MÁQUINA

IDENTIFICAÇÃO
- Nome da Máquina
- Código interno
- Tipo
- Fabricante
- Modelo
- Número de Série
- Data de Aquisição

INFORMAÇÕES ADICIONAIS
- Observações

Foi decidido não cadastrar inicialmente:
- Status
- Localização
- Ano de fabricação
- Dados operacionais

Essas informações poderão fazer parte da tela de detalhes/gestão da máquina posteriormente.

CÓDIGO X NÚMERO DE SÉRIE

- Código = identificação interna da empresa.
- Número de Série = identificação original fornecida pelo fabricante.

Exemplo:
  Máquina: Torno CNC 01
  Código: MC-001
  Fabricante: ROMI
  Modelo: GL 240
  Nº de Série: 123456789

ESTADO ATUAL DO PROJETO

A fundação do Black Forge está definida. A interface, a arquitetura dos módulos, a estrutura inicial do estoque, o backend, o banco de dados e o conceito de máquinas já foram estabelecidos.

O próximo grande passo é transformar Máquinas, Ordens de Serviço, Estoque e Manutenção em módulos completamente conectados ao banco de dados, consolidando a integração entre frontend React, API ASP.NET Core e SQL Server.
